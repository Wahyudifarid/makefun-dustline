DUSTLINE is a round-based tactical FPS: you are a Vanguard attacker with 4 bot teammates against 5 Sentinel defenders on the Kestrel Foundry map. Plant the charge at Relay Alpha or Relay Beta (45 s fuse) or eliminate the enemy team, earn credits each round, and spend them in the buy menu on carbines, SMGs, a DMR, armor and grenades. First to 7 rounds wins. Bots follow waypoint routes, hold angles, rotate, plant and defuse, and react to sight and sound. The game is static files only (three.js vendored, WebAudio synth sounds, canvas-generated textures) and runs in desktop Chrome with no network request.

## Run it

```sh
node serve.ts
```

Then open http://localhost:8080 in desktop Chrome. WASD to move, mouse to look (click to lock), left click to fire, R to reload, B for the buy menu, E to plant/defuse, 4/5/6 for grenades.
